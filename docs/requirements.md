# 宝贝星球 - 详细需求文档

## 1. 项目概述

**宝贝星球**是一个面向 0-6 岁宝宝父母的全功能育儿网站，采用移动优先设计，提供宝宝成长记录、疫苗管理、社区交流、专家咨询等功能。

### 技术栈
- 前端：Next.js 14 (App Router) + TypeScript + Tailwind CSS
- 后端：Next.js API Routes + Prisma ORM + PostgreSQL
- 认证：NextAuth.js（邮箱密码 + Google/微信 OAuth）
- 存储：Cloudflare R2（免费 10GB）
- 部署：Vercel 免费层

### 免费优先原则
所有第三方服务优先使用免费方案，预留升级接口。

## 2. 用户故事

### 2.1 新用户注册与引导
> 作为一位新手妈妈，我希望快速注册账号并创建家庭，以便开始记录宝宝的成长。

**验收标准：**
- 支持邮箱注册和 Google/微信一键登录
- 3步引导流程：注册 → 创建家庭 → 添加宝宝
- 新用户赠送 100 积分

### 2.2 宝宝档案管理
> 作为家长，我希望为每个宝宝建立独立档案，记录基本信息。

**验收标准：**
- 支持上传头像（R2 预签名直传）
- 记录姓名、性别、生日、血型、出生体重/身高
- 一个家庭最多 5 个宝宝

### 2.3 日常记录
> 作为忙碌的家长，我希望用最少的点击记录喂养、睡眠、换尿布。

**验收标准：**
- 快捷添加按钮（1-2次点击完成记录）
- 计时器功能（记录喂养/睡眠时长）
- 仪表盘展示今日统计摘要
- 支持历史记录查看和编辑

### 2.4 生长曲线
> 作为关注宝宝发育的家长，我希望看到宝宝的生长曲线与 WHO 标准对比。

**验收标准：**
- 录入体重、身高、头围数据
- 自动生成百分位曲线图（P3/P15/P50/P85/P97）
- 标记宝宝在同龄儿童中的百分位

### 2.5 疫苗管理
> 作为家长，我希望系统自动提醒疫苗接种时间。

**验收标准：**
- 根据生日自动生成疫苗时间表
- 支持标记已接种/跳过
- 即将到期的疫苗提醒通知

### 2.6 成长相册
> 作为家长，我希望上传宝宝照片并自动分类整理。

**验收标准：**
- 支持批量上传照片到 R2
- 浏览器端 AI 自动识别照片内容（Transformers.js + MobileNet）
- 按月/标签分组浏览
- 无限滚动加载

### 2.7 社区交流
> 作为家长，我希望能与其他父母交流育儿经验。

**验收标准：**
- 加入/创建育儿圈子
- 发帖、评论、点赞
- 文本内容敏感词过滤（DFA 算法）
- 图片内容浏览器端 nsfwjs 审核
- 违规内容自动拦截

### 2.8 专家咨询
> 作为遇到育儿问题的家长，我希望能咨询专业人士。

**验收标准：**
- 浏览专家列表和个人主页
- 使用积分或免费咨询券预约
- 基础聊天功能
- 每月 2 次免费咨询

### 2.9 知识库
> 作为求知的家长，我希望能查阅专业的育儿知识文章。

**验收标准：**
- 按分类浏览文章
- 搜索功能
- 文章详情页带结构化数据（SEO）

### 2.10 推送通知
> 作为忙碌的家长，我希望收到重要的育儿提醒。

**验收标准：**
- Web Push 推送（疫苗提醒、喂养提醒）
- Brevo 邮件通知（每日摘要）
- 支持通知偏好设置

## 3. 免费服务额度与升级触发条件

| 服务 | 免费额度 | 升级触发条件 | 升级方案 |
|------|----------|-------------|---------|
| Cloudflare R2 | 10GB 存储 + 10GB/月出站 | 存储 >8GB 或流量 >8GB/月 | R2 付费 ($0.015/GB/月) |
| Brevo 邮件 | 300封/天 | 日发送量 >250 | Brevo 付费套餐 |
| Vercel 部署 | 100GB/月带宽 | 带宽 >80GB/月 | Vercel Pro |
| Transformers.js | 无限（浏览器端） | 无 | 无需升级 |
| nsfwjs | 无限（浏览器端） | 无 | 无需升级 |
| Web Push | 无限 | 无 | 无需升级 |
| PostgreSQL | 需自建或 Supabase 免费层 | 数据量 >500MB | Supabase Pro 或自建 |
